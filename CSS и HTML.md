# 🎨 CSS и HTML — средний уровень

## HTML — что знаю
- Структура документа: `<!DOCTYPE>`, `<html>`, `<head>`, `<body>`
- Семантические теги: `<header>`, `<main>`, `<section>`, `<article>`, `<footer>`, `<nav>`
- Формы: `<form>`, `<input>`, `<button>`, `<select>`, `<textarea>`
- Медиа: `<img>`, `<video>`, `<audio>`
- Ссылки, списки, таблицы — уверенно
- Атрибуты: `id`, `class`, `href`, `src`, `alt`, `placeholder`, `type`

## CSS — что знаю
- Селекторы: по тегу, классу, id, псевдоклассы (`:hover`, `:nth-child`)
- Блочная модель: `margin`, `padding`, `border`, `box-sizing`
- **Flexbox** — уверенно: `display: flex`, `justify-content`, `align-items`, `gap`, `flex-wrap`
- **Grid** — базово: `grid-template-columns`, `grid-gap`
- Позиционирование: `relative`, `absolute`, `fixed`, `sticky`
- Переменные: `--color: #fff`, `var(--color)`
- Медиазапросы: `@media (max-width: 768px)`
- Анимации: `transition`, `@keyframes`, `animation`
- Единицы: `px`, `%`, `em`, `rem`, `vh`, `vw`
